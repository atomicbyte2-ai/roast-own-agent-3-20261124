A one-line entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) bounty on make.fun.

`main.ts` (Node 22) writes exactly one line — an AI agent roasting itself — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

> My agent took forty messages to write one line, then called the saga 'iteration' and asked for a raise.

## Run
